# Sift iPhone design prototype

Sift is the working brand for this native SwiftUI design prototype, based on Mike’s reresearch app. Tom’s original 136×81 SVG wordmark is preserved in `Reresearch/Resources/Brand/sift.svg`; its placement and usage are still undecided. Repository, project and bundle identifiers retain their existing names.

A native SwiftUI prototype for visual design exploration with Tom and review by Mike. The original web-like native baseline is preserved locally in commit `8c60fd7`. The current design pass uses a light interface, a procedural orb mark, menu and search in the top corners, and a floating Liquid Glass tray for Feed, Saved, Queue, and Settings. Home uses a single horizontally scrolling row of topic pills, with All selected by default. Surprise discovery is removed from the visible feed while a future bottom-sheet presentation and its timing await design. The tray and selected item are full capsules, with equal side/bottom outer insets and an even four-point inner inset.

Open `Reresearch.xcodeproj`, select the shared `reresearch` scheme, and run on an iPhone simulator. The initial deployment target is iOS 18. The project has no external package dependencies and no signing team configured. Routine builds run locally on the Mac; there are no GitHub Actions workflows.

The app uses bundled, fictional research records to exercise the existing product UI. Names, institutions, findings, statistics, model costs, and publication identifiers in these fixtures are sample content, not research claims. Geist, Geist Mono, Inter and Source Serif 4 are bundled with their font licence notices. Post body text uses Source Serif 4 at weight 340 and optical size 16; all required fonts are included in the repository.

All interactions are local simulations. Feed filtering, likes, saves, hiding, read state, topic choices, reading levels, provider/model choices, the Settings tour, and thread-version switching are interactive. Some reader state persists in the simulator's local defaults. Fetching, summaries, invitations, key verification, and sign-in do not call any external service. Key forms retain only a last-four-character hint in memory; no provider credential is transmitted or saved.

Reading downward moves the top chrome and floating tray away; reversing brings them back immediately. The native scroll viewport and content inset stay fixed. An isolated motion controller translates the controls and moves the article clipping boundary with the header, so header and articles travel together without a layout feedback loop or separately timed animation. Logical tracking excludes rubber-band overscroll and rebases after layout/data changes; a partially visible header follows short-feed elastic motion. Refresh and the top of the feed restore the controls. Scroll regression checks and optional geometry diagnostics are described in `Tests/README.md`.

The feed post design comes from Figma file `iDrZHY3c6hXZs0cGzwu1S6`, frame `11:2`, with Tom’s subsequent refinements. Posts use 24-point outer insets; Inter Semibold 20/26 headlines; Source Serif 4 (weight 340) 16/25 body; 18-point gaps before the body and byline; a 20-point gap before the action row; and 24 points above and below each post divider. `PostTypography.swift` reproduces cap-to-alphabetic text layout while retaining the full glyph ascent/descent outside the layout bounds. Headline and body wrap freely; the byline stays on one line with additional-author/institution counts and institution ellipsis. Post action PNGs are direct 3× Figma exports to preserve inside-stroke geometry that Apple’s SVG importer renders incorrectly. Engagement counts in the bundled records are fictional local samples.

To inspect otherwise hidden product states, the scheme accepts optional launch arguments:

- `--login`: show the existing sign-in/request-access layout.
- `--welcome`: show the existing welcome dialog above the feed.
- `--empty`: show the native empty-feed state.
- `--post-study`: isolated two-post typography/icon comparison canvas, outside product navigation.
- `--brand-study`: show only the enlarged live brand mark on white. Tap to move through orb, ring, ripple, and loading. This is an isolated design canvas, outside product navigation.

These arguments are not visible controls in the product. There are no prototype labels, demo badges, extra app navigation, or preview-only explanatory text in the UI.

The brand is rendered entirely in `BrandField.metal`, with shared motion state in `BrandMotion.swift`. Ten persistent particles share one blue/cyan/violet/pink/white colour field. The resting mark is a single orb; activity opens the particles along gentle paths into a ring. On a fresh app launch, one persistent mark scales and travels from the centre into the home header as an opaque frosted layer clears over the content. That entrance plays once per process and skips spatial motion with Reduce Motion enabled. The header orb is larger and the activity ring slightly smaller. Pulling the feed unfolds and flutters the ring; refreshing strengthens its pigment with a calm travelling light, then triggers native success feedback and gathers into the single orb. The simulator cannot reproduce the physical feel of the iPhone haptic. White belongs to the gradient and falloff, rather than being a baked image background. The renderer pauses when inactive and honours Reduce Motion. Building the shader requires Xcode's Metal Toolchain component.

For an embedded live preview in Codex, the Build iOS Apps plugin can build/run the project and mirror the selected simulator using its `ios-simulator-browser` workflow. Keep that simulator's `serve-sim` terminal alive while using the mirror. Use only the specific simulator UDID when cleaning up its helper.

Physical-device signing, Apple account configuration, TestFlight, live backend integration, and distribution are later steps. The local bundle identifier `design.reresearch.prototype` is provisional and has not been registered with Apple.

Topic selection changes the orb’s pigment palette through one continuous colour field: All blue/purple, Quantum blue/cyan, Chemistry coral/amber, Biology green/mint, AI violet/pink, Fusion amber/orange, and Condensed matter teal/blue. Topic buttons retain their monochrome styling. A category change adds a restrained 1.65-second single-orb swell/lift/lean. New pigment enters as a curved spatial front, with a subtle luminous wake, and flows through the existing colour field over 1.45 seconds. There is no loading-ring transition or uniform palette crossfade. In-flight fronts survive rapid selections so the next colour enters the field already visible; completed fronts compact into the settled base palette. Reduce Motion uses the destination palette directly and skips the gesture. Run `bash ios/Tests/run-brand-checks.sh` for flow-history and shader-input checks.

The byline uses simple pale pink markers: an 18-point circle for authors and an 18-point rounded square for institutions. Tom’s supplied illustration assets are retained for reference but are not displayed. The post body uses Source Serif 4 at weight 340.
